SportStrata · data integrity

The bug that never threw an error

Problem
The college football scoreboard showed about 25 games a week. The real number was up to 99. A request was missing one parameter (groups=80), so the upstream API quietly returned only the ranked-leaning subset. The parsers are built to degrade gracefully, so nothing failed and nobody was told. It ran that way for weeks.
Fix
Added the parameter and verified it against live data in a real browser: 99 events rendered, 74 of which had been invisible.
Prevention
Built an upstream contract monitor: a daily GitHub Actions job that hits the production API proxies, checks every field the client reads, and asserts count invariants, so a "well-formed but incomplete" response fails loudly. Full write-up → It also catches the other failure class I'd already hit once: a proxy receiving a WAF block page instead of JSON.
SportStrata · availability

Closing an open relay before it caused an outage

Problem
A review pass found no rate limiting on any /api/* proxy. Anyone could use them as a free relay to ESPN, Sleeper and MLB, which meant one abuser could get the site's egress IP banned upstream: a full outage.
Fix
Shipped edge middleware: 120 requests per rolling minute per IP, 429 with Retry-After, preflight exempt, bounded memory. The client already handled fetch failures with an error state and retry, so users see no difference.
Honest limit
It's per-isolate, so it damps abuse rather than enforcing a hard quota. That's written down in the decision record, with a Cloudflare WAF rule specified as the real backstop.
BotChase · debugging

Making failures visible

Problem
The metrics endpoint returned a 500 because database row objects weren't JSON-serializable, and parts of the dashboard swallowed errors instead of showing them.
Fix
Fixed the serialization, added proper error pages, and removed the silent failure paths so a broken request surfaces instead of rendering an empty screen. Moved outbound email from SMTP to an HTTPS API, and pinned every dependency to an exact version for reproducible builds.
